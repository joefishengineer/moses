# Contributing

Change the instructions through a pull request into `main` rather than a direct push. Assistants that track this repo (for example, a Grok Bot built on it) pick up merged pull requests automatically, and a pull request gives everyone a chance to review the change first.

Keep this repo general: scholarship rules only. Team- or church-specific rules (who reviews work, where files go, your own statement of faith) belong in your own copy or your own assistant's setup, not here.
